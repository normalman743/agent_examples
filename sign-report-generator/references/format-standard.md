## 标准概述

本规范依据公文排版规范整理，规定了公文标题、主送单位、正文、结构层次序数、附件说明、附件六个要素的排版要求。本规范适用的公文不涉及发文机关标志、发文字号、印章、版记、页码等复杂版头/版记要素，排版以本规范六条为准。

---

## 一、标题

- 一般用 **2 号方正小标宋体字**
- 可分一行或多行**居中**排布
- 回行时要做到：
  - 词意完整
  - 排列对称
  - 长短适宜
  - 间距恰当
- 标题排列应当使用**梯形或菱形**

**例**：
```
关于召开新公文系统操作
    的通知
```

---

## 二、主送单位

- 标题下**空一行**
- 左侧**顶格**用 **3 号仿宋体字**标识
- 回行时仍**顶格**
- 最后一个主送单位名称后标**全角冒号**

**例**：
```
各直属单位，集团公司各部门，各区域审计中心：
```

---

## 三、正文

- 编排在主送单位名称**下一行**
- 每自然段**左空二字**，回行**顶格**
- 回行时**不能将数字、年份拆开**
- 正文用 **3 号仿宋体字**
- 文中如有小标题，可用**黑体字**或**楷体字**
- 正文除图表外，行间距用**固定值 28 磅**

---

## 四、序号

文中结构层次序数依次可以用"一、"、"（一）"、"1."、"（1）"标注：

| 层次 | 序号形式 | 字体 |
|------|----------|------|
| 第一层 | 一、 | 黑体字，**不加粗** |
| 第二层 | （一） | 楷体字，**加粗** |
| 第三层 | 1. | 仿宋体字，**加粗** |
| 第四层 | （1） | 仿宋体字，不加粗 |

**结构层次只有二层的，也可以用"一、""1."标注**（跳过"（一）"这一层）。

**例**：
```
一、XXXX
（一）XXXX
1．XXXX
（1）XXXX
```

---

## 五、附件说明

- 公文如有附件，在正文**下空一行左空二字**，用 **3 号仿宋体字**标注附件名称
- 格式为"附件"后标**全角冒号**和名称
- 附件如有序号，使用**阿拉伯数码**（如"附件：1.×××"）
- 附件名称后**不加标点符号**
- 附件名称较长需回行时，应当与上一行附件名称的**首字对齐**

**例**：
```
附件：1．XXXXXXXXXXXXXXXXXXXXXXX
      2．XXXXXXXXXXXXXXXXXXXXXXXXXXXX
        XXXXXXX
```

---

## 六、附件

- "附件"二字及附件顺序号用 **3 号黑体字**，**顶格**编排在版心左上角第一行
- 附件标题一般用 **2 号方正小标宋体字**，**居中**编排在版心第三行
- 附件的顺序号和附件标题应当与附件说明的表述**一致**

**例**：
```/
附件 1
参会人员登记表
```

## 字体字号速查表

| 要素 | 字体 | 字号 | 说明 |
|------|------|------|------|
| 标题 | 方正小标宋体 | 2号 | 居中，可梯形/菱形回行 |
| 主送单位 | 仿宋体 | 3号 | 左侧顶格，回行顶格 |
| 正文 | 仿宋体 | 3号 | 左空二字，回行不拆数字/年份 |
| 正文小标题（如有） | 黑体或楷体 | 3号 | 视层级选用 |
| 第一层次序号（一、） | 黑体 | 3号 | 不加粗 |
| 第二层次序号（（一）） | 楷体 | 3号 | **加粗** |
| 第三层次序号（1.） | 仿宋体 | 3号 | **加粗** |
| 第四层次序号（（1）） | 仿宋体 | 3号 | 不加粗 |
| 附件说明 | 仿宋体 | 3号 | 正文下空一行左空二字 |
| 附件（"附件"二字+序号） | 黑体 | 3号 | 顶格，版心左上角第一行 |
| 附件标题 | 方正小标宋体 | 2号 | 居中，版心第三行 |

---

## 排版检查要点

- [ ] 标题：2号方正小标宋体，居中，回行是否符合梯形/菱形要求
- [ ] 主送单位：标题下空一行，左侧顶格3号仿宋体，最后一个单位后是否为全角冒号
- [ ] 正文：主送单位下一行，每段左空二字，回行是否顶格，是否拆分了数字/年份
- [ ] 正文行距：是否为固定值28磅
- [ ] 结构层次：第二层楷体是否加粗、第三层仿宋体是否加粗
- [ ] 结构层次：仅两层时是否正确使用"一、"+"1."
- [ ] 附件说明：是否为3号仿宋体，附件名称后是否误加了标点
- [ ] 附件：顶格"附件"+序号是否为3号黑体，附件标题是否为2号方正小标宋体并居中
- [ ] 附件顺序号、标题是否与附件说明表述一致
