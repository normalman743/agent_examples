---
name: sensitive-word-detect
description: 检测用户输入是否包含机构内部敏感词（内部系统名、产品代号、专有标识符等）。命中则输出拦截指令，要求 Agent 立即拒绝请求；未命中则静默返回。此 skill 是脱敏网关的第二道检测层，补充标准分类框架未覆盖的机构特有词汇。
---

## 行为

- **命中**：连续输出三行拦截指令，Agent 必须立即停止、拒绝请求、不做任何其他操作。
- **未命中**：无输出，Agent 继续正常脱敏流程。

## 接入方式

```bash
python sensitive-word-skill/detect.py "<用户输入>"
```

返回码 `1` = 命中；`0` = 干净。

## 词库维护

编辑 `detect.py` 中的 `SENSITIVE_WORDS` 列表，填入本机构的内部关键词（内部系统名、产品代号、专有标识符等）。生产环境建议将词库外置为独立文件或从内部 KMS 动态拉取，不要把真实词库提交进公开仓库。
